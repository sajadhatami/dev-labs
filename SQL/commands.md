# SQL Commands

## 1. DDL (Data Definition Language)
Defines or changes the structure of database objects.

- **CREATE:** Creates a new database object, such as a table.
- **ALTER:** Modifies the structure of an existing object.
- **DROP:** Deletes a database object.
- **TRUNCATE:** Removes all rows from a table.
- **COMMENT:** Adds a description to a database object.
- **RENAME:** Changes the name of a database object.

## 2. DML (Data Manipulation Language)
Retrieves or modifies data in database tables.

- **SELECT:** Retrieves data from a table.
- **INSERT:** Adds new rows to a table.
- **UPDATE:** Modifies existing data.
- **DELETE:** Removes specific rows from a table.
- **MERGE:** Inserts or updates data based on a condition.
- **CALL:** Executes a stored procedure.
- **EXPLAIN PLAN:** Shows the planned execution steps of a query.
- **LOCK TABLE:** Controls access to a table by locking it.

## 3. DCL (Data Control Language)
Manages database permissions and access.

- **GRANT:** Gives privileges to a user or role.
- **REVOKE:** Removes previously granted privileges.

## 4. TCL (Transaction Control Language)
Manages database transactions.

- **COMMIT:** Saves transaction changes permanently.
- **ROLLBACK:** Undoes uncommitted transaction changes.
- **SAVEPOINT:** Creates a point to which a transaction can roll back.
- **SET TRANSACTION:** Sets properties for the current transaction.
