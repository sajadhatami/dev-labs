# TDD (Test Driven Development) — توسعه تست‌محور

**تعریف:**  
در TDD قبل از نوشتن کد، ابتدا تست نوشته می‌شود. بعد کد نوشته می‌شود تا تست پاس شود.

چرخه TDD:

```
RED → GREEN → REFACTOR

1. RED
نوشتن تستی که شکست می‌خورد

2. GREEN
نوشتن کمترین کد برای پاس شدن تست

3. REFACTOR
تمیز کردن و بهبود کد
```

### مثال:

می‌خواهیم تابع جمع بسازیم.

اول تست:

```
def test_add():
    assert add(2, 3) == 5
```

تست شکست می‌خورد چون هنوز تابع نداریم.

بعد کد:

```
def add(a, b):
    return a + b
```

حالا تست پاس می‌شود.

بعد اگر لازم بود کد را بهتر می‌کنیم.

---

### تمرکز TDD:

```
Function
   ↓
Class
   ↓
Module
```

یعنی بیشتر روی جزئیات داخلی کد تمرکز دارد.

---

### مزایا:

- کد قابل اعتمادتر می‌شود.
- طراحی بهتر می‌شود.
- تغییر دادن کد با خیال راحت‌تر انجام می‌شود.
- باگ‌ها زودتر پیدا می‌شوند.

---

# BDD (Behavior Driven Development) — توسعه رفتارمحور

**تعریف:**  
در BDD به جای تمرکز روی کد، روی رفتار مورد انتظار کاربر تمرکز می‌کنیم.

یعنی می‌پرسیم:

> کاربر چه انتظاری از سیستم دارد؟

---

ساختار اصلی BDD:

```
Given → When → Then
```

### مثال:

قابلیت ورود کاربر:

```
Feature: User Login

Scenario: Successful login

Given:
کاربر حساب معتبر دارد

When:
رمز صحیح وارد می‌کند

Then:
کاربر وارد پنل می‌شود
```

---

### تمرکز BDD:

```
User Behavior
      ↓
System Behavior
      ↓
Code
```

یعنی تست می‌کند که سیستم از دید کاربر درست کار کند.

---

### مثال در فروشگاه:

BDD:

```
Given:
محصول موجود است

When:
کاربر خرید را انجام می‌دهد

Then:
سفارش ساخته می‌شود
و موجودی کم می‌شود
```

نه اینکه:

```
test_update_stock()
test_create_order()
```

---

# تفاوت TDD و BDD

|ویژگی|TDD|BDD|
|---|---|---|
|تمرکز|کد|رفتار کاربر|
|سطح تست|پایین‌تر|بالاتر|
|مخاطب|برنامه‌نویس|برنامه‌نویس + تیم محصول|
|زبان|معمولاً Python/Java|معمولاً زبان ساده مثل Gherkin|
|تست می‌کند|تابع و کلاس|قابلیت و سناریو|
|مناسب برای|طراحی داخلی|نیازمندی‌های کسب‌وکار|

---

# ارتباط TDD و BDD

این دو رقیب نیستند؛ مکمل هم هستند:

```
             Application

        BDD Tests
     (User Behavior)

             ↓

    Integration Tests

             ↓

        TDD Tests
    (Functions / Classes)
```

مثلاً در یک پروژه Django:

**BDD:**

```
کاربر ثبت‌نام می‌کند
ایمیل تایید دریافت می‌کند
```

**TDD:**

```
test_hash_password()
test_validate_email()
test_create_user()
```
